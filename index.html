智能眼镜 · 通用目视检查 — 项目原型

设备：双目全彩 · 屏幕 640×400 · 交互：语音 + 滚轮 + 按钮 · 前置：登录 → 选工单 → 确认作业

进入流程体验 →

从登录开始逐步浏览：拍照留底 → 回看 → 上传 → 结束任务

从登录开始逐步浏览：能力菜单 → 识别置信度 → 比对入库 → 结束任务

基础版

  • 拍照留底 — 全语音解放双手，仅采集全彩图像
  • 镜头预览 — 开关预览、调整位置
  • 设备端检视 — 放大、移动、切换照片
  • 留档上传 — 按当前工单挂接至收货系统

AI 算法版（增强版）

  • 紧固件视觉计数 — 输出数量 + 置信度，准确率要求 ≥98%
  • 外文证书视觉翻译 — 逐段翻译 + 段落置信度
  • 外文发票信息捕捉 — PO / 件号 / 数量等，逐字段置信度
  • 数据关联入库 — 系统比对 + 设备端编辑 → 标准入库数据

基础版逻辑 · 拍照留底

确认作业后进入拍照留底模式：双目全彩预览 → 全语音拍照 → 设备端回看 → 按工单上传留档。
① 登录→ ② 选工单→ ③ 确认作业→ ④ 预览/拍照→ ⑤ 回看→ ⑥ 上传留档→ ⑦ 结束任务
▸ 基础版流程 · 图像采集与工单挂接

增强版逻辑 · 辅助功能

确认作业后进入增强能力菜单（非直接拍照）：选择能力 → 拍照识别 → 置信度/准确率 → 修正 → 比对入库 → 结束任务。
登录、选工单与基础版相同；从确认作业开始流程即不同。
① 登录→ ② 选工单→ ③ 确认作业→ ④ 选增强能力→ ⑤ 识别+置信度→ ⑥ 比对/入库→ ⑦ 结束任务

交互与设备规格

硬件：双目全彩智能眼镜 · 640×400 显示
输入：语音（全场景）+ 滚轮 + 按钮（短按确认 / 长按返回或拖动）
基础版：拍照、预览、留档、按工单上传
增强版：信息提取 + 置信度/准确率 + 低置信度修正 + 设备端入库
体验：顶部「进入流程体验」从登录串联至结束 · 各屏也可单独打开
